# Tarjuman for Android

Signed Android builds of **Tarjuman (تُرجُمَان)**, a native Android live voice translation app: two people share one pair of earphones and each hears the other in their own language. The source code is private; this repository only hosts the latest release.

## Install

1. Open the download link on your Android phone.
2. Open the downloaded file. If Android asks, allow installing apps from your browser.
3. New versions install over the old one and keep your settings and conversations. The app tells you when an update is available.

## Requirements

- Android 7.0 or newer
- An internet connection: translation runs on Google Gemini
- A free Gemini API key from Google AI Studio (the app shows how to get one)
- Age 18 or older

## Privacy

Your Gemini key, settings and saved conversations stay on your phone. Speech is sent only to Google's Gemini API to be translated.

`latest.json` describes the current release. The app reads it to offer updates.
